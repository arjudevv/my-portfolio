# Arjun — Developer Portfolio

Interactive 3D portfolio built with Next.js, React Three Fiber, GSAP, and Framer Motion.

## Live Site

Deployed automatically to **Vercel** on every push to `main`.

## Development

```bash
cd apps/web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

See [apps/web/README.md](apps/web/README.md) for full documentation.

## Vercel Deployment

This is a monorepo. In your [Vercel project settings](https://vercel.com/dashboard), set:

- **Root Directory:** `apps/web`
- **Framework Preset:** Next.js (auto-detected)

Vercel deploys automatically when you push to `main`. No extra configuration required.
